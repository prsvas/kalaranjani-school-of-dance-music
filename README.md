# Bharatanatyam & Classical Arts Website

A free, responsive static website designed for a Bharatanatyam / Indian Classical Arts institution.

## Files

- `index.html` — complete website structure
- `style.css` — visual design and responsive layout
- `script.js` — WhatsApp, Google Form, mobile menu and news-card settings
- `assets/images/` — place your own licensed/approved images here

## Quick setup

1. Create a GitHub repository, for example `bharatanatyam-website`.
2. Upload all files and folders from this package.
3. In GitHub, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.
6. GitHub will provide the public website address.

### Google Form

Open `script.js` and replace:

`enquiryFormUrl: "https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform"`

with your actual Google Form URL.

If you prefer an embedded form, replace the "Google Form Embed Area" in `index.html` with the iframe generated by Google Forms.

### Student photographs

Place approved images in `assets/images/` and replace the photo-placeholder divs in `index.html` with image tags.

Example:

`<img src="assets/images/student-01.jpg" alt="Bharatanatyam student performance">`

Only publish photographs where you have appropriate permission.

### News

The site deliberately uses short original summaries and links to the original publishers. Do not scrape and republish full articles or copyrighted photographs without permission.
